# Hello Java! 🚀

A repository for learning and organizing Java from basics to advanced topics.

## 📚 Learning Content

This project covers various Java libraries and core concepts through example codes.

### 1. Java Core

- **`lang`**: Basic Java libraries and classes such as `Object`, `String`, `Integer`, etc.
- **`wrapper`**: Wrapper classes for handling primitive types as objects and Auto Boxing
- **`clazz`**: Utilizing class information and metadata
- **`nested`**: Understanding Nested Classes and Inner Classes
- **`exception`**: Exception handling mechanisms and custom exceptions

### 2. Generics & Collections

- **`generics`**: Using Generics for type safety
- **`collection`**: Utilizing various data structures such as `List`, `Set`, `Map`, `Deque`, etc.
- **`util`**: Utility classes used throughout the project

### 3. Date & Time

- **`time`**: Java 8+ Date and Time API including `LocalDate`, `LocalTime`, `Duration`, `Period`, etc.

### 4. Functional Programming & Streams

- **`functional`**: Using functional interfaces
- **`lambda`**: Basics and advanced usage of Lambda expressions
- **`methodref`**: Code simplification through Method References
- **`optional`**: Using `Optional` to prevent `NullPointerException`
- **`stream`**: API for data stream processing (basics and operations)
- **`parallelstream`**: Parallel stream processing for performance improvement

### 5. Multi-Threading & Concurrency

- **`thread`**: Core multi-threading concepts including thread creation, control, synchronization, `ExecutorService`,
  `CAS`, etc.
- **`thread/sync`**: Synchronization and Lock mechanisms
- **`thread/bounded`**: Producer-Consumer pattern using Bounded Queues

### 6. IO & Networking

- **`io`**: Streams, file processing, and Buffered IO
- **`charset`**: Character encoding and charset handling
- **`tcp`**: TCP socket communication (V1 ~ V6, including chat server examples)

### 7. Advanced Topics

- **`reflection`**: Reflection techniques for analyzing and manipulating class information at runtime
- **`defaultmethod`**: Using Default Methods in interfaces

## 🛠️ How to Run

You can check the examples by running the `Main` class or test codes within each package.
